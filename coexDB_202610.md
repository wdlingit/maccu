## Database collection, 202610

We are making efforts on collecting read counts, postprocessing, and building database tables. We are now working on a few model species. Available updates of database files can be found at this [link](https://data.depositar.io/en/organization/maccu-co-ex-database-files-collection) ([depositar](https://data.depositar.io/en/)). Also see [our approaches](https://github.com/wdlingit/maccu/blob/main/DB_from_DEE2.202610.md) for downloadeding specified SRS metadata and classifying samples.

**NOTE**: This collection is currently under construction.
